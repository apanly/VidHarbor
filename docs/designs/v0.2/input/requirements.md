## 统一 yt-dlp 调度与状态展示

- 描述：所有下载、元数据探测、频道首次同步、手动检查和定时检查必须通过唯一的 yt-dlp 管理器提交任务，由管理器统一维护 queued、running、succeeded、failed、canceled 生命周期，负责取消和服务停止收尾，并在界面展示排队任务、运行任务、任务类型和执行结果；只有媒体下载沿用现有并发限制，其余任务不限制并发，src/yt-dlp.ts 只保留固定参数协议、进程执行和输出解析职责。
- issue整理:
  - 做什么：新增唯一的 yt-dlp 管理与调度入口，禁止业务模块绕过管理器启动 yt-dlp，并向界面提供调度状态。
  - 边界：纳入当前已存在的下载、元数据探测、频道首次同步、手动检查和定时检查；各类任务不共享并发额度，只有媒体下载沿用现有 download_concurrency 限制，其他任务不限制并发，不设置任务优先级。
  - 最终决策：统一入口、统一调度、统一任务生命周期、统一取消与停机收尾、统一界面状态展示；下载维持现有并发限制，其余任务无限并发，底层 yt-dlp 参数和解析模块不承载业务调度。
