# Historical Design Records

Each version directory contains planning and implementation artifacts such as product requirements, technical design, task breakdowns, bugfix notes, and review reports.

These files are preserved for traceability. A review finding marked "needs fix" records the result at that historical review point and may already be fixed by a later task or commit. Do not treat historical review files as the current defect list.

For current user-visible behavior and deployment instructions, use the repository root `README.md` and `CHANGELOG.md`.

Unreleased contract deltas that supersede historical snapshots without rewriting them live under [`unreleased/`](unreleased/).
