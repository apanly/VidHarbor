## 下载支持自定义分类文件夹

- 描述：下载时支持选择或填写保存到的相对文件夹，文件夹不存在时自动创建；已完成下载支持移动到另一个相对文件夹。
- issue整理:
  - 做什么：直下载和频道批量下载都支持目标文件夹，完成后也可把整个下载目录移动到另一个目标文件夹。
  - 边界：只允许 downloads 挂载内的相对路径；禁止绝对路径、..、.、空路径段和路径逃逸；目标 downloadId 目录已存在时失败；不做自动作者分类、分类表、文件夹管理页、标签系统、磁盘目录树扫描。
  - 最终决策：复用 downloads.target_subdirectory；null 保持当前根目录行为；下载仍保持每个 downloadId 一个独立目录；UI 提供保存到文件夹输入框、完成项移动入口和基于已有 target_subdirectory 的最近文件夹选项。
- 来源: Gitea #21
