VidHarbor / 60 seconds

一分钟 快速上手

从容器启动，到完成第一条视频下载。只讲最短路径。

VidHarbor 是一个部署在可信内网中的本地视频管理和下载工具。下面用一分钟完成部署和第一条视频下载。

Step 01 / Deploy

四行命令，启动服务

  • 1准备独立目录
  • 2获取官方 Compose 配置
  • 3启动并等待容器健康
首先准备一个目录，下载官方 Compose 配置，然后启动容器。Docker 会根据机器自动选择 AMD64 或 ARM64 镜像。

$ mkdir vidharbor

$ cd vidharbor

$ curl --fail --location \

  https://raw.githubusercontent.com/apanly/VidHarbor/main/compose.image.yaml \

  --output compose.yaml

$ docker compose up -d

$ docker compose ps

healthy

Step 02 / Open

打开你的 本地港口

容器健康后，在浏览器进入本机的 3002 端口。

容器健康后，在浏览器打开 localhost 3002 端口。
http://localhost:3002
仅部署在可信内网，请勿直接暴露到公网

Step 03 / Configure

确认配置，即可开始

  • 1确认下载根目录为只读的 /downloads
  • 2按机器性能选择下载并发数
首次使用先确认下载根目录，并按机器性能设置下载并发数。下载根目录由部署配置固定，不能在页面修改。
配置管理

Step 04 / Create

粘贴地址，开始下载

  • 1下载 → 新建直下载
  • 2粘贴有权保存的公开单视频地址
  • 3保持直连与视频类型，可选最高分辨率
进入下载页面，粘贴一个公开单视频地址。默认配置可以直接使用，也可以选择最高分辨率，然后创建下载任务。
https://www.youtube.com/watch?v=...

进度，清清楚楚

在“下载中”查看实时进度、下载速度、预计剩余时间、网络路径与开始时间。

下载中可以实时查看进度、速度和预计剩余时间。

Step 06 / Done

下载完成，即刻可用

  • ✓查看标题、时长与文件大小
  • ✓确认总耗时与存储路径
  • ✓直接预览或保存文件
完成后可以查看文件大小、总下载耗时和存储路径，也可以直接预览或保存文件。下载内容会持久化保存在 downloads 目录中。
