### WA-23 · 模态框、页签与确认提示 — 失败

- 语言：`zh-CN`、`en`
- 路由：`/downloads`、`/channels?page=2`、`/channels/1`、`/authorizations`、`/settings`
- 受控数据：本地下载、频道 5、频道检查、非敏感授权状态和 Fixture Proxy
- 检查：双语新增下载/频道/代理及编辑授权模态框、双语频道详情页签、删除确认提示
- 实际：所有模态框和页签均按当前语言正确显示；中文下载确认显示“确认永久删除下载…及其文件？”且成功取消。随后频道确认检查中，`evaluate_script` 的默认 dialog action 先于显式 `handle_dialog dismiss` 接受了确认，本地频道 5 被删除；检测到总数由 25 变 24 后已用原始 fixture 恢复为 25。为避免重复违规，英文删除确认未继续执行
- 控制台：模态框和页签未见错误；意外删除本身没有控制台错误
- 网络请求：意外产生了本项禁止的本地频道删除写请求；这正是失败依据
